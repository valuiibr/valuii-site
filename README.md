# Site Valuii — Inteligência em Negócios

Site institucional estático, responsivo e preparado para publicação no GitHub Pages.

## Publicação no GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. No GitHub, acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
5. Para domínio próprio, informe `www.valuii.com.br` em **Custom domain**.

## Domínio

O arquivo `CNAME` já está configurado para `www.valuii.com.br`. Após a ativação do GitHub Pages, ajuste os registros DNS conforme indicado pelo GitHub.
